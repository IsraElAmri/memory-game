# Memory Game

A card-matching memory game built with vanilla HTML, CSS, and JavaScript for a web development course project.

Players are shown 16 celebrity faces during a 60-second memorisation phase, then must find the right face
when given a name before time runs out.

**Live demo**: [IsraElAmri.github.io/memory-game](https://IsraElAmri.github.io/memory-game)

## How to play

1. Memorize which face is where during the 60-second memorisation phase.
2. When the game asks you to find a name, click the correct card before time runs out.
3. Your score increases for each correct answer.

## Stack

HTML5, CSS3, Vanilla JavaScript — no build step, runs directly in a browser.
